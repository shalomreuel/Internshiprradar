# Referral workflow

This engine does **not** scrape private LinkedIn data, bypass login walls, or guess who can refer you.

It surfaces leads using public GitHub organization membership and public profile data.

## Daily workflow
1. Open `data/opportunities.csv` and shortlist roles that fit your profile.
2. For a company with a configured GitHub organization, open `data/referral_targets.csv`.
3. Inspect the person's public GitHub profile and recent work.
4. Confirm the person actually works at/contributes to the target organization before contacting them.
5. Prefer public technical overlap with the role.
6. Ask for advice first; ask about a referral only after a genuine interaction.

## Outreach template

Hi <Name> — I'm a student in India focused on AI/ML and GenAI, and I found <role> at <company>. I noticed your work on <specific project/repo>. I've built <one relevant project> and I'm applying for the role. If you have a moment, I'd appreciate any advice on what the team looks for in interns. Thanks!

If they respond positively, you can later ask whether they are comfortable referring you. Don't spam multiple employees with identical messages.
