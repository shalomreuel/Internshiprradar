# Referral workflow

The engine uses only public GitHub information. It does not scrape private LinkedIn data or bypass login walls.

1. Review `data/opportunities.csv`.
2. For interesting companies, open `data/referral_targets.md`.
3. Verify the person's current connection to the company.
4. Prefer genuine technical overlap with the role.
5. Ask for advice before asking for a referral; do not spam.

Suggested message:

> Hi <Name> — I'm a student in India focusing on AI/ML and GenAI, and I found <role> at <company>. I noticed your work on <specific project/repo>. I've built <one relevant project> and I'm applying for the role. If you have a moment, I'd appreciate any advice on what the team looks for in interns. Thanks!
